04 The Difference

05 Architecture & Platform

Real HOLON, behind one clean layer

Wired in — and it never dead-ends.

  • Two live calls on @ontomorph/holon-client: concepts.search() resolves every substance; interactions.checkList() screens the whole list.
  • Thresholds grounded in NHS · FDA · EFSA guidance — every flag carries its source and evidence grade.
  • Educational tool, not a medical device: consent gate, disclaimers, emergency routing — it points to care, never replaces it.
Say it straight Real HOLON integration lives behind the service layer. With no key or a flaky venue network it falls back to a deterministic clinical-rule engine — set VITE_HOLON_API_KEY and it goes live, no code change.
